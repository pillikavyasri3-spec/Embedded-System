# STM32 LED Blinking

## Objective
To interface an LED with an STM32 microcontroller and control its ON/OFF operation.

## Components Used
- STM32 Microcontroller
- LED
- Resistor
- Jumper wires
- Breadboard

## Software Used
- STM32CubeIDE

## Working
The STM32 microcontroller is programmed to turn the LED ON and OFF at regular time intervals. This is a basic embedded-system project used to understand GPIO configuration and digital output control.

## Applications
- Basic GPIO testing
- Embedded-system learning
- Microcontroller hardware interfacing

## Future Improvements
The project can be extended to control multiple LEDs, sensors, and other peripherals.
